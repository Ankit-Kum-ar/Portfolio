# Personal Portfolio

Welcome to my personal portfolio! This project showcases my journey as a frontend developer and highlights my skills, projects, and background in an elegant, responsive web application. The portfolio is designed to provide a seamless user experience, reflecting both my technical expertise and design sensibilities.

## 🔗 Live Demo
[Check out the live site on Vercel!](https://ankit--roan.vercel.app/)

## 📄 Overview

This personal portfolio features four main pages:

- **Home**: A brief overview of who I am, my resume, and important sections to explore more about me.
- **About**: Detailed information about my professional background, experience, and what drives me as a developer.
- **Projects**: A curated showcase of projects I've developed, with links to repositories and live demos where applicable.
- **Tech Stack**: A comprehensive list of the technologies, languages, and tools I use in my development workflow.
- **Contact**: A simple, user-friendly contact form where visitors can reach out to me.

## 🌟 Key Features

- **Responsive Design**: The entire portfolio is optimized for both desktop and mobile screens.
- **Smooth Navigation**: Easy transitions between pages using `react-router-dom`.
- **Interactive UI Elements**: Custom icons from `react-icons` and modern design elements.
- **Contact Form**: Seamless form submission functionality powered by EmailJS for direct communication.
- **Lightweight and Fast**: Built with Vite for fast bundling and loading times.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/), [Tailwind CSS](https://tailwindcss.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Email Handling**: [EmailJS](https://www.emailjs.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Routing**: [React Router DOM](https://reactrouter.com/)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/Ankit-Kum-ar/portfolio.git
    cd portfolio
    ```

2. **Install dependencies**:
    ```bash
    npm install
    ```

3. **Run the development server**:
    ```bash
    npm run dev
    ```

4. **Open in your browser**: 
    Navigate to `http://localhost:3000` to see the portfolio live.
